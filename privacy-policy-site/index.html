# Политика конфиденциальности приложения «Мои маршруты» - **Дата вступления в силу:** 14 августа 2026 г. - **Разработчик:** Apixa **Контакт по вопросам конфиденциальности:** support@apixa.ru Приложение «Мои маршруты» работает без регистрации, рекламы, удалённой аналитики и облачного профиля. Ниже описано, какие данные нужны приложению и как они обрабатываются. ## Геопозиция и маршруты С разрешения пользователя приложение получает точную или примерную геопозицию, высоту, скорость и время. Эти данные используются для записи GPS-трека, расчёта дистанции и скорости, отображения позиции на карте и контроля отклонения от выбранного маршрута. Во время записи, которую пользователь явно запускает кнопкой GO, приложение работает как foreground service с геолокацией. Поэтому маршрут продолжает записываться при выключенном экране или когда открыто другое приложение, а Android показывает постоянное системное уведомление. Запись прекращается после завершения маршрута пользователем. Приложение не запрашивает разрешение на постоянный фоновый доступ к геопозиции (`ACCESS_BACKGROUND_LOCATION`). ## Локальное хранение GPS-треки, импортированные маршруты, настройки и локальный журнал ошибок хранятся в памяти устройства. Данные треков защищены шифрованием AES-256, ключ хранится средствами Android Keystore. Приложение не загружает маршруты на сервер Apixa. ## Карты и сетевые сервисы Для отображения онлайн-карт приложение по HTTPS загружает тайлы со следующих сервисов: - OpenStreetMap — `tile.openstreetmap.org`; - CyclOSM — `tile-cyclosm.openstreetmap.fr`. Эти сервисы получают обычные данные сетевого запроса, включая IP-адрес и координаты запрошенного участка карты. Их обработка регулируется правилами соответствующего сервиса. Если пользователь указывает URL для загрузки MBTiles, сервер по этому адресу также получает сетевой запрос. Пользователь может импортировать локальный MBTiles-файл и пользоваться картой без сетевых запросов к провайдерам онлайн-тайлов. ## Экспорт и передача данных GPX-файл передаётся другому приложению или сервису только после явного нажатия «Экспорт» и выбора получателя в системном меню Android «Поделиться». После передачи обработка файла регулируется политикой выбранного пользователем приложения или сервиса. Для экспорта создаётся временная копия GPX в кэше приложения. Она может сохраняться до очистки кэша Android или данных приложения. ## Срок хранения и удаление Маршруты хранятся до удаления пользователем. Доступны следующие способы удаления: - удалить отдельный маршрут в списке маршрутов; - выбрать «Удалить все данные» в настройках приложения; - удалить данные приложения или само приложение средствами Android. Разработчик не может восстановить удалённые локальные маршруты, поскольку их копии не хранятся на сервере Apixa. ## Безопасность Локальные треки защищены шифрованием AES-256. Сетевые запросы приложения выполняются по HTTPS. Пользователю не следует экспортировать маршрут в приложение или сервис, которому он не доверяет. ## Изменения политики Если способы обработки данных изменятся, текст политики и дата её вступления в силу будут обновлены. Вопросы можно направлять на support@apixa.ru. --- # My Routes Privacy Policy - **Effective date:** August 14, 2026 - **Developer:** Apixa **Privacy contact:** support@apixa.ru My Routes works without registration, advertising, remote analytics, or a cloud profile. ## Location and routes With the user's permission, the app accesses precise or approximate location, altitude, speed, and time. This data is used to record GPS tracks, calculate distance and speed, display position on the map, and detect deviation from a selected route. During a recording explicitly started by the user with the GO button, the app runs a location foreground service. This lets recording continue while the screen is off or another app is open, and Android displays an ongoing system notification. Recording stops when the user finishes the route. The app does not request all-the-time background location access (`ACCESS_BACKGROUND_LOCATION`). ## On-device storage GPS tracks, imported routes, settings, and the local crash log are stored on the device. Track data is protected with AES-256 encryption, with the key protected by Android Keystore. The app does not upload routes to an Apixa server. ## Maps and network services Online map tiles are loaded over HTTPS from OpenStreetMap (`tile.openstreetmap.org`) or CyclOSM (`tile-cyclosm.openstreetmap.fr`). These providers receive ordinary network-request data, including the IP address and coordinates of the requested map area. Their own policies govern this handling. If the user supplies a URL for downloading an MBTiles file, that server also receives the request. The user can import a local MBTiles file and use it without requests to online tile providers. ## Export and sharing A GPX file is sent to another app or service only after the user explicitly taps Export and selects a destination in Android's share sheet. The selected recipient's policy governs subsequent processing. A temporary GPX copy may remain in the app cache until Android clears it. ## Retention and deletion Routes remain until the user deletes them. Individual routes can be removed from the route list, all local content can be erased with Clear All Data, and Android can remove all content by clearing the app's data or uninstalling it. Apixa cannot restore deleted routes because it keeps no server copy. ## Security and changes Local tracks are protected with AES-256 encryption, and app network requests use HTTPS. Users should not export a route to an app or service they do not trust. If data handling changes, this policy and its effective date will be updated. Questions can be sent to support@apixa.ru.
